# Export Blazor TreeGrid to Excel with Complete Customization

A quick-start Blazor WebAssembly application (.NET 10) that shows how to export the Syncfusion Blazor Tree Grid to Excel and CSV. It also includes code to customize the file name, theme, header, and footer of the exported Excel document.

**Online example**: https://blazor.syncfusion.com/demos/tree-grid/exporting

## Features

* Excel export support using the built-in TreeGrid export functionality.
* Customizing the exported Excel file name.
* Applying custom themes and styles to the exported workbook.
* Adding custom header/footer content to the exported Excel document.
* Exporting hierarchical TreeGrid data while preserving its structure.
* Triggering Excel export through the TreeGrid toolbar.
* Configuring export settings using `ExcelExportProperties`.

## Prerequisites

* [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
* Visual Studio 2026 / Visual Studio Code

## How to Run the Project

**Visual Studio 2026**

1. Clone or download this repository.
2. Open the project file:

   `TreeGridExcelExportSample.csproj`

3. Restore all NuGet packages.
4. Build the project.
5. Run the application using **Ctrl+F5**.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root.

```bash
cd export-blazor-treegrid-to-excel-with-complete-customization
dotnet restore
dotnet run
```

Open the URL displayed in the terminal after the application starts.
